# Personal-Portfolio

Personal portfolio website for **Aalok Barnawal** — Graphic Designer & Front-End Developer.

## Project Structure

```
.
├── css/
│   ├── style.css         # Main styles for index.html
│   └── 404.css           # Styles for 404.html
├── js/
│   ├── main.js           # Interactive scripts for index.html
│   └── 404.js            # Interactive scripts for 404.html
├── favicon/              # Site favicons and web manifest
├── hero-image.webp       # Hero image asset
├── index.html            # Main portfolio page
├── 404.html              # Custom 404 error page
└── README.md             # Project documentation
```

## Features

- **Modular Architecture**: Clean separation of semantic HTML5, Vanilla CSS3, and Vanilla JavaScript.
- **Modern Aesthetic**: Dark mode theme with vibrant gradient accents and glassmorphism.
- **Micro-Interactions**: Ambient cursor glow, 3D perspective card tilt, magnetic buttons, and smooth scroll reveals.
- **Responsive**: Fully responsive across mobile, tablet, and desktop viewports.
- **Contact Form**: Web3Forms integration for email submissions.
